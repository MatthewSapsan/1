# Terraria-like Browser MVP

Небольшой прототип 2D sandbox-игры в браузере в духе Terraria.

## Если совсем с нуля — сделай вот так (самый простой путь)

Ниже максимально короткая инструкция, без лишнего:

1. Открой папку проекта (где лежит `index.html`).
2. Открой в этой папке **Терминал**.
3. Введи команду:

```bash
python3 -m http.server 8000
```

4. Открой браузер (Chrome/Firefox/Edge).
5. В адресной строке открой:

```text
http://localhost:8000
```

6. Игра запущена.
7. Когда закончишь — вернись в терминал и нажми `Ctrl + C` (это остановит сервер).

---

## Что нужно установить заранее

Обычно уже ничего не нужно, но желательно иметь **Python 3**.

Проверить:

```bash
python3 --version
```

Если увидел что-то вроде `Python 3.10.x` — всё готово.

Если команда не найдена:
- установи Python с официального сайта: https://www.python.org/downloads/
- при установке включи опцию добавления Python в PATH (если есть такой чекбокс)
- после установки закрой/открой терминал и снова проверь `python3 --version`

## Как открыть терминал (очень подробно)

### Windows

1. Открой папку проекта в Проводнике.
2. Кликни в адресную строку папки.
3. Введи `cmd` и нажми Enter.
4. Откроется терминал уже в нужной папке.

### macOS

1. Открой папку проекта в Finder.
2. Запусти приложение Terminal.
3. Перетащи папку проекта в окно Terminal (подставится путь).
4. Нажми Enter, затем выполни:

```bash
cd <путь_к_папке>
```

(или сразу открой терминал в папке через контекстное меню, если включено)

### Linux

1. Открой папку проекта в файловом менеджере.
2. ПКМ по пустому месту → «Open in Terminal» / «Открыть в терминале».

## Проверка, что ты в правильной папке

В терминале выполни:

```bash
pwd
```

Потом:

```bash
ls
```

В выводе должны быть файлы:
- `index.html`
- `styles.css`
- `main.js`

Если их нет — ты не в той папке.

## Запуск через Python (рекомендуется)

1. В терминале (в папке проекта) выполни:

```bash
python3 -m http.server 8000
```

2. Открой в браузере:

```text
http://localhost:8000
```

3. Чтобы остановить сервер: `Ctrl + C`.

### Если порт 8000 занят

Запусти на другом порту:

```bash
python3 -m http.server 8080
```

И открывай:

```text
http://localhost:8080
```

## Альтернатива без сервера

Можно просто открыть `index.html` двойным кликом.

Но если что-то работает странно — используй способ с `python3 -m http.server`, он надёжнее.

## Управление в игре

- `A/D` или стрелки — движение;
- `W` / `Space` / `↑` — прыжок;
- `ЛКМ` — копать блок;
- `ПКМ` — поставить выбранный блок;
- `1..4` или колесо мыши — выбор блока.

---

## Как понять, что всё запустилось

После открытия `http://localhost:8000` ты должен увидеть:
- фон и блоки мира;
- персонажа;
- подсказки в левом верхнем углу.

Проверка за 10 секунд:
1. Нажми `A` или `D` — персонаж двигается.
2. Нажми `Space` — персонаж прыгает.
3. ЛКМ по блоку рядом — блок ломается.

## Если не работает

### Открывается пустая страница

1. Нажми `F12` → вкладка **Console**.
2. Если есть красные ошибки — пришли их текст.
3. Проверь, что сервер запущен именно из папки, где `index.html`.

### Пишет, что команда `python3` не найдена

Попробуй:

```bash
python --version
python -m http.server 8000
```

(На некоторых Windows-системах используется команда `python`, а не `python3`.)

### ПКМ открывает меню вместо установки блока

В игре контекстное меню отключено, но если оно появляется:
- попробуй Chrome/Firefox/Edge;
- обнови страницу (`Ctrl + R`).
