# Terraria-like Browser MVP

Небольшой прототип 2D sandbox-игры в браузере в духе Terraria.

## Что есть

- процедурный тайловый мир (трава/земля/камень/дерево);
- камера, следующая за игроком;
- гравитация, прыжок и коллизии;
- добыча блока ЛКМ и установка блока ПКМ;
- простой инвентарь и выбор текущего блока.

## Как запустить (подробно)

### 1) Подготовка

1. Убедись, что в папке проекта есть файлы:
   - `index.html`
   - `styles.css`
   - `main.js`
2. Открой терминал в этой папке.

Проверка текущей папки:

```bash
pwd
```

Проверка файлов:

```bash
ls
```

---

### 2) Быстрый способ — открыть напрямую

Можно просто дважды кликнуть `index.html`.

Если игра открылась и работает — этого уже достаточно.
Если браузер блокирует часть поведения или хочется стабильнее, используй локальный сервер из шага 3.

---

### 3) Рекомендуемый способ — через локальный сервер

#### Вариант A: Python (самый простой)

Проверь Python:

```bash
python3 --version
```

Запусти сервер в папке проекта:

```bash
python3 -m http.server 8000
```

После этого открой в браузере:

- `http://localhost:8000`

Остановить сервер: `Ctrl + C` в терминале.

#### Вариант B: Node.js (если Python нет)

Проверь Node:

```bash
node --version
```

Запуск через `npx`:

```bash
npx serve .
```

Открой адрес, который покажет команда (обычно `http://localhost:3000`).

---

## Управление

- `A/D` или стрелки — движение;
- `W` / `Space` / `↑` — прыжок;
- `ЛКМ` — копать блок;
- `ПКМ` — поставить выбранный блок;
- `1..4` или колесо мыши — выбор блока.

## Частые проблемы и решения

### Белый/пустой экран

1. Открой DevTools (`F12`) → вкладка **Console**.
2. Проверь, что нет ошибок загрузки `main.js`/`styles.css`.
3. Убедись, что запускаешь из папки, где лежит `index.html`.

### Порт 8000 занят

Запусти на другом порту:

```bash
python3 -m http.server 8080
```

И открой:

- `http://localhost:8080`

### Не работает ПКМ (контекстное меню)

В игре контекстное меню отключено специально для установки блока. Если меню всё же появляется, попробуй другой браузер (Chrome/Firefox/Edge).

### Сильно лагает

- Закрой лишние вкладки браузера.
- Уменьши масштаб окна.
- Проверь, не запущены ли тяжёлые процессы в системе.

## Мини-проверка после запуска

Если всё ок, то:

1. Персонаж двигается влево/вправо.
2. Персонаж прыгает на `Space`.
3. ЛКМ ломает блок рядом с персонажем.
4. ПКМ ставит выбранный блок.
5. Колесо мыши переключает выбранный блок.
